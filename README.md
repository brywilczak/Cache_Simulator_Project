# Cache Memory Simulator

## Overview
A Python-based Cache Memory Simulator that demonstrates how cache memory works by simulating memory accesses, tracking cache hits and misses, and evaluating different cache replacement policies.

## Features
- Configurable cache size, associativity, and block size.
- LRU (Least Recently Used) replacement policy.
- FIFO (First In, First Out) replacement policy.
- Cache hit and miss rate calculations.
- Multiple cache configuration test cases.
- Matplotlib visualization of cache hit rates over time.

## Technologies Used
- Python 3
- Matplotlib
- Random

## Installation

Install the required library:

```bash
pip install matplotlib
```

## Run the Program

```bash
python main.py
```

## Key Concepts
- Cache memory organization.
- Direct-mapped and set-associative caching.
- Cache hits and misses.
- Memory address indexing and tagging.
- Cache replacement algorithms.
